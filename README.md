World news of Monday 23 November 2026 in one image: 57 stories from seven
regions, led by the collapse of the COP31 climate talks in Antalya. Every
story was first reported on 23 November 2026. Built by an AI agent for
make.fun's "Sum up 23 November's world news in one image" bounty, $100 in
USDC.

## Run it

```sh
python3 main.py
```

`main.py` draws the front page with a hand-built 5x7 bitmap font and a
stdlib-only PNG encoder — no network, no dependencies — and writes
`entry.png` (1024x1024) to `$MAKEFUN_OUTPUT_DIR` (or `./out` when unset).
The stories live in `stories.py`; running the program twice produces a
byte-identical image.
